# Pinterest Clone API

# This is a simple Pinterest clone API built with Node.js, Express, and MongoDB.

# It allows users to create, read, update, and delete pins, boards, and users.

# Features

# - User authentication (register, login, logout)

# - Create, read, update, and delete pins

# - Create, read, update, and delete boards

# - Add pins to boards
